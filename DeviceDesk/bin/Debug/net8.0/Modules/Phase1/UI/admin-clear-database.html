Clear Phase 1 Receiving Batches

ℹ️ What This Does:

This will remove all Phase 1 receiving batches (the batches shown in "All Receiving Activity").

⚠️ Will Be Deleted:
  • All Receiving Batches (RB-2025-001, RB-2025-002, etc.)
  • All Collection Slips
  • All Receiving Batch Items and Scans
  • All New Stock scanning sessions
  • All RnR scanning sessions
✅ Will Be Preserved:
  • All Phase 0 Orders (uploaded via CSV)
  • All Phase 0 Order Lines
  • User accounts
  • School data

After clearing, your Phase 0 orders will be ready for receiving again!
