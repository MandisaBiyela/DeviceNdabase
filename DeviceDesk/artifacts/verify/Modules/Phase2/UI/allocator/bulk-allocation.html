Automatic Location Assignment

How it works:

  • Each device will receive a unique bin location
  • Devices will share Building, Room, Rack, and Shelf until full
  • Bins are automatically assigned sequentially (01, 02, 03...)
  • Starting location is determined from the school's zone
  • If shelf fills up, the system automatically moves to the next shelf
  • If rack fills up, the system automatically moves to the next rack
